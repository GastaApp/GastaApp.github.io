## 🌱 About Gasta

**Gasta** is a Progressive Web App (PWA) designed to make personal expense tracking simple, accessible, and convenient.

Whether you're monitoring daily spending or building better financial habits, Gasta aims to help you keep track of your expenses and become more mindful of where your money goes.

As a PWA, Gasta supports offline use, allowing you to access supported functionality even without an internet connection.

## ✨ Features

- 💰 **Expense Tracking** — Keep track of your spending.
- 📊 **Spending Insights** — Get a clearer picture of your expenses.
- 🗂️ **Expense Organization** — Keep your financial records organized.
- 📱 **Installable PWA** — Install Gasta on supported devices for an app-like experience.
- 📴 **Offline Support** — Access supported features without an internet connection.
- 🌐 **Web-Based Access** — Use Gasta directly through your browser.

## 📲 How to Install

Gasta can be installed on supported devices through a compatible browser.

- **Android:** Open Gasta in Chrome and select the Install App option if available.
- **Desktop:** Open Gasta in a supported browser and use the installation option.
- **iPhone / iPad:** Open Gasta in Safari, tap Share, then select Add to Home Screen.
